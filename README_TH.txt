FITBEAT V4.2 Faster + Sensor Fix

ไฟล์สำหรับอัปโหลดทับ 4 ไฟล์เดิมใน GitHub mid-02:
- game.js: โน้ตออกถี่ขึ้น ~1.15–2.1 วินาที และช่วงเวลานับคะแนนกว้างขึ้น
- controller.js: ลดเกณฑ์แรงเหวี่ยงจาก 3.1 เป็น 1.9 m/s² เพิ่มการตอบสนอง
- dual-sensor.js: เพิ่มช่วงจับคู่กล้องและโทรศัพท์จาก 420 เป็น 850 ms
- camera.js: ลดความถี่การประมวลผลสูงสุดประมาณ 22 FPS เพื่อลดภาระเครื่อง

หมายเหตุ: ไม่เปลี่ยน BPM เพลงหรือเวลาของด่าน การลดเกณฑ์เซนเซอร์อาจทำให้เกิด false positive ได้ ต้องทดสอบจริง และการปรับ FPS เป็นเพียงความพยายามลดโหลด ไม่รับประกันว่าจะเร็วขึ้นทุกเครื่อง

ก่อนอัปโหลดสำรองไฟล์เดิม และหลังอัปโหลดให้รีโหลดทั้งคอมและโทรศัพท์
