FITBEAT V5 — Rhythm & Motion Update

อัปโหลดไฟล์ทั้งหมดจาก ZIP นี้ไปยัง root ของ GitHub repository mid-02 (แทนไฟล์เดิม)
ตรวจสอบผ่าน GitHub Pages หลังเผยแพร่ และรีเฟรชแบบไม่ใช้แคช

- Warm-up 60s 100 BPM; Light 60s 115 BPM; Moderate 90s 128 BPM
- Vigorous 120s 140 BPM; Maximum 120s 150 BPM
- Interval 180s เพลง 150 BPM, ท่าช้า/เร็วสลับทุก 30 วินาที
- Cool-down 60s 90 BPM
- ท่าตามลำดับที่ออกแบบ, ซ้ายขึ้น-ลง 4 รอบ, กางแขนสองข้างพร้อมกัน 8 ครั้งในระดับ Moderate ขึ้นไป
- Start Game: READY → 3 → 2 → 1 → GO!
- Keep Screen Awake บน controller.html (ขึ้นอยู่กับการรองรับของเบราว์เซอร์; ห้ามล็อกหน้าจอ)
- กล้องตรวจท่าที่เปลี่ยนแปลงและป้องกันการนับท่าค้างซ้ำในระยะสั้น

หมายเหตุ: โน้ตถูกจัดเวลาเป็นจำนวนเต็มของ beat ของเพลงสังเคราะห์ที่มีอยู่; ยังต้องทดสอบจริงกับกล้องและมือถือ
ท่า FORWARD ที่ใช้กล้องด้านหน้าอาจตรวจจับยากเพราะการยื่นแขนเข้าหากล้องต้องใช้ข้อมูล depth
ระหว่าง Warm-up/Cool-down ท่าชกสลับจะวนต่อเมื่อครบชุดก่อนหมดเวลา
