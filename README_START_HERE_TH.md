# FITBEAT — Rebuilt V1 (ทดลอง)

เวอร์ชันนี้ใช้ **ภาพฉาก 5 ระดับ ภาพน้องหมา เมนู เพลงสังเคราะห์ ระบบ Warm-up/Workout/Cool-down และคะแนน** จาก FITBEAT เดิม และเปลี่ยนเกมเป็น **สองเลน LEFT ARM / RIGHT ARM** โดยเพิ่ม MediaPipe 3D Camera.

## เริ่มใช้งาน
- แตก ZIP แล้วนำ **ไฟล์และโฟลเดอร์ภายใน** ไปวางที่ root ของเว็บไซต์ HTTPS (หรือใช้ localhost)
- เปิด `index.html` เลือกระดับ แล้วกด **เปิดกล้อง** ภายในหน้าเกมเพื่ออนุญาตกล้อง
- หากยังไม่เปิดกล้อง ทดสอบได้ด้วย **1 2 3 4** (แขนซ้าย) และ **Q W E R** (แขนขวา) ตามลำดับ **Up / Side / Forward / Down**
- สคริปต์กล้องใช้ `vision_bundle.mjs` และ `pose_landmarker_lite.task` ที่แนบมา ส่วนไฟล์ WASM ใช้จากเว็บไซต์เดโมเดิม จึงต้องมีอินเทอร์เน็ต

## สถานะ / ข้อจำกัด
- เป็นชุดทดลองรวมไฟล์ **ยังไม่ได้ทดสอบกับกล้องจริงในเบราว์เซอร์**
- ท่า Forward อาจไม่แม่นยำเมื่อแขนบังกัน; Spin / Hold / Repeat ยังไม่เพิ่มในรุ่นนี้
- กล้องอ่านทุก ~40ms เพื่อลดภาระเครื่อง; โน้ตหนึ่งตัวให้คะแนนได้ครั้งเดียว
- **ไม่แก้ไขและไม่ลบ repository หรือไฟล์ต้นฉบับเดิม**
