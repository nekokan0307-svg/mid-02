FITBEAT V4 — Camera & Phone Setup

เปลี่ยน:
1. หน้าเมนูหลักมีปุ่ม Camera & Phone Setup
2. เปิดกล้อง + สร้าง Pair Code + เลือกแขนที่ถือโทรศัพท์ ในหน้าเดียวกัน ก่อนเข้าเล่นเกม
3. ภาพกล้องซ่อนระหว่างเล่นเสมอ (MediaPipe ยังอ่านภาพจากวิดีโอเบื้องหลัง)
4. หน้า Setup มี checkbox เปิดดูภาพตัวอย่างขนาดเล็กเฉพาะขณะตั้งค่า
5. หน้าเล่นเกมมีปุ่มกลับไปตั้งค่าเซนเซอร์
6. เก็บระบบภาพ/เพลง/คะแนน/กล้อง/Phone Controller เดิมไว้

วิธีใช้:
- อัปโหลดไฟล์ใน ZIP ทั้งชุดไปยัง repository/hosting ใหม่หรือแทนที่เฉพาะไฟล์ที่แก้
- เปิด index.html ผ่าน HTTPS
- กด Camera & Phone Setup จากหน้า Home
- เปิดกล้อง และกด สร้างรหัสเชื่อมต่อ
- เปิด controller.html บนโทรศัพท์ กรอกรหัส กดเชื่อมต่อ และเปิดเซนเซอร์
- กลับไปเลือกระดับและเล่นเกม

หมายเหตุ:
- ยังไม่ได้ทดสอบจับคู่กับอุปกรณ์จริงหรือยืนยันการทำงานของ PeerJS server
- ถ้าโทรศัพท์ไม่เชื่อมต่อ ดูสถานะที่หน้า Setup และตรวจอินเทอร์เน็ตทั้งสองเครื่อง
- ไม่ได้แก้ไข GitHub
